Results and evaluation

Evaluating a design vector (solve_structure, GeometricProperties), the results it returns, the reductions over them (compliance, axial_force, axial_stress), and materializing a design back into a model (updatemodel).

AsapOptim.GeometricProperties — Type
GeometricProperties(x, p::OptParams)

Geometry-only evaluation of a design — positions, lengths, areas — with NO structural solve. Use for objectives like material volume (dot(geo.A, geo.L)) where paying for a solve would be waste.

Fields

  • X::Matrix, L::Vector, A::Vector
source
AsapOptim.OptResults — Type
OptResults

Outputs of one design evaluation (solve_structure), carrying everything downstream objectives and constraints consume — all plain data, so gradients of any scalar of these fields flow back to the design vector.

Fields

  • U::Vector: full-space displacements, 6 slots per node in the order ux, uy, uz, θx, θy, θz — node i's translations are U[6(i−1) .+ (1:3)] (e.g. all z-displacements are U[3:6:end])
  • X::Matrix: evaluated node positions (3 × n_nodes)
  • A::Vector: evaluated per-element areas
  • L::Vector: evaluated element lengths
  • sections::AbstractVector: the evaluated per-element sections (feed to further pure computations if needed)
  • EA::AbstractVector: evaluated axial rigidities (plain vector — cheap under reverse AD)
  • F::Vector: the full-space load vector the design was solved for — P − Pf(x) with design-dependent element loads (p.loads = :design), else the base-design p.F
  • ends: the evaluated per-element EndConditions (joint variables), or nothing when the problem has none

axial_stress(res::OptResults, p::OptParams) -> Vector

Per-element axial stress [force/length²]: axial force over evaluated area.

AsapOptim.solve_structure — Method
solve_structure(x, p::OptParams) -> OptResults

Evaluate a design vector: scatter positions and areas, build the load vector (element-load fixed-end forces re-evaluated at the design when p.loads = :design), run Asap's pure solve on the resulting ModelState, and package the results. Fully differentiable — Zygote.gradient(x -> f(solve_structure(x, p)), x0) needs nothing else, and the gradient includes the load path.

solve_truss and solve_frame are aliases (the unified core needs no distinction).

source
AsapOptim.updatemodel — Method
updatemodel(p::OptParams, x) -> Model

Materialize a design vector back into the reference Asap.Model: write the evaluated node positions and element sections into the model, re-solve, and return it. The returned model is the ordinary mutable definition object — ready for post-processing, force recovery, visualization, or export.

(The model's topology is untouched, so the frozen analysis cache is reused; this is a numeric re-assembly plus one factorization.)

source

AsapOptim extends two of Asap's accessors on OptResults (the functions belong to Asap, so they are listed here by method):

Asap.compliance — Method
compliance(res::OptResults, p::OptParams) -> Real

External work Fᵀu of the evaluated design — the canonical smooth stiffness objective. F is the design's own load vector (res.F): with design-dependent element loads it varies with the design, and the gradient includes that term.

source
Asap.axial_force — Method
axial_force(res::OptResults, p::OptParams) -> Vector

Per-element axial force [force], tension-positive, matching Asap's stateful axial_force(res, el) (slot 7 of the local end forces f = k·u_local + q̃: the axial action at the END node): EA/L times the axial elongation, plus the axial fixed-end force q̃₇ of any element loads on the member (an inclined loaded beam, self-weight on a column, …), evaluated at the design when p.loads = :design. Pure and differentiable; exact for truss elements and for frame elements with rigid axial connections.
