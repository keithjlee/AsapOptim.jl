# AsapOptim v1.3.0

Shells and rigid diaphragms. Requires Asap 1.3.

## Added

- **`ThicknessVariable(elements, value, lb, ub)`**: one design entry sets the thickness of a
  set of `ShellSection` elements (a wall, a slab panel group). Stiffness (membrane ∝ t,
  bending ∝ t³, shear ∝ t) and self-weight (∝ ρt) follow it. Absolute semantics, like
  `AreaVariable`.
- **`shell_volume(x, p)`**: Σ t·area of the shell elements at the design, differentiable
  and solve-free: the material-cost term for thickness optimization.
- **`OptParams` and `solve_structure` accept models with `ShellElement`s and
  `RigidDiaphragm`s.** Shell surface loads (self-weight, pressure) follow the design, like
  frame element loads. Diaphragm models solve through Asap's exact constraint map.
- **`solution_tangents`** (implicit differentiation) covers shells (thickness and
  shell-node geometry, design-dependent shell loads) and rigid diaphragms. Verified against
  finite-difference Jacobians of `solve_structure`.

## Fixed (latent with Asap 1.3)

- `solve_structure` decided whether the load vector follows the design from frame loads
  only; shell self-weight and pressure would have stayed frozen.
- `solve_structure` called the reduced solve directly and would have bypassed rigid
  diaphragms; it now goes through the constraint map whenever the model has one.

## Performance

Reverse-mode (Zygote) gradients through Asap 1.3 cost a fixed multiple of the solve at any
model size (frames about 13×, shells about 20×), down from a cost that grew with the model.
See Asap's v1.3.0 release notes.

## Compatibility

`OptParams` gained fields for thickness variables at the end (before `solver`); code that
reads fields by name is unaffected. Existing truss and frame problems give the same solutions
as 1.2; Zygote gradients of frame problems agree to about 1e-14 (they now go through Asap 1.3's
reverse rules).
