# AsapOptim v1.4.0

Multi-case solves, mirrored and directional couplings, and triangular shells. Requires Asap 1.4.

## Added

### Several load cases at one design
- `LoadCases(p; cases)` collects the per-case nodal loads, frozen load vectors, static fixed-end
  forces and frame-load case masks from the model's case tags.
- `solve_cases(x, p, lc)`: one assembly and one factorization, a multi-RHS solve. `U` and `F` are
  `n_dof × n_cases`; design-dependent frame-load fixed-end forces are evaluated per case. Per-case
  `compliance`, `axial_force` and `axial_stress` methods take `lc`.
- Verified against one `OptParams` per case (design and frozen loads) and by superposition;
  Zygote ≡ ForwardDiff ≡ the sum of single-case gradients.
- Design-dependent shell surface loads (quadrilateral or triangle) are not supported in
  `LoadCases` yet: use `loads = :frozen`, or one `OptParams` per case.

### Couplings
- `CoupledVariable(target, parent, factor; direction, mirror)`: a node coupled to a
  `SpatialVariable` can move along its own direction, or along the parent's direction reflected
  across a plane (`mirror = :X`, `:Y`, `:Z` or a normal vector) — symmetric pairs with one design
  entry. The default is unchanged.

### Triangular and mixed shell meshes
- `ThicknessVariable`, `shell_volume`, `solve_structure` and `solution_tangents` work on Asap 1.4's
  triangular `ShellElement`s and on mixed quadrilateral/triangle meshes (shell surface loads on
  triangles follow the design like those on quadrilaterals).

## Compatibility
- Existing problems give the same results as 1.3.
- `CoupledVariable` gained a `direction` field; code that reads fields by name is unaffected.
